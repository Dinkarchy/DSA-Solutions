## Problem

Declare a variable  **hour**  and initialize it with the value $5$ Then, calculate and print the total number of minutes and seconds present in this hour.

Input
Output


## Solution

**Language:** c_cpp  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-15T14:01:19.276Z  

```c_cpp
#include <iostream>
using namespace std;

int main() {
    int hour = 5;
    cout << (60*hour) << endl;
    cout << (60*60*hour);

}

```
